# Web Programming Lab - HTML Lists and Gallery

A collection of early HTML exercises.

## Pages
- `List.html` - nested ordered/unordered lists about studying Computer Science and favorite snacks
- `Gallery.html.html` - image gallery
- `Entities.html` - HTML entities practice

## Assets
The repository includes small image files, including `cedar.gif`, `coffee.jpg`, `laptop.png`, and `sea.jpg`.

## Open locally
Download the HTML pages and images into one folder. Double-click any HTML file to open it in a browser. No server is needed.

## Learning goals
Practice HTML lists, images, entities and links. These are coursework examples, not a finished website. Some of the original HTML markup can be improved for better nesting and accessibility.
